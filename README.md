# Smart Coaching Management System

A full-stack MERN web application developed for managing coaching institute operations efficiently.

## Features

- Student Registration and Login
- Teacher Login
- Attendance Management
- Notes Upload and Download
- Fee Management
- Dashboard for Students and Teachers
- Secure Authentication
- Responsive User Interface

## Tech Stack

### Frontend
- React.js
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB

## Project Structure

- Frontend: React Application
- Backend: Node.js & Express API
- Database: MongoDB
